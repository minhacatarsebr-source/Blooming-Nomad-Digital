# Perguntas para o cliente

Use só as que se aplicam; mensagem curta, amigável, em inglês por padrão, começando pela boa notícia.

- Booking/checkout tool: which plan, and can we get admin access?
- Do customers pay when they book/order, or only reserve?
- Which action is the main conversion (booking, purchase, form, WhatsApp, call)?
- Running or planning Google Ads / Meta Ads?
- Access to Google Analytics, Tag Manager and Meta Business.
- Privacy policy: existing text or template to review; legal business details.
- Cookie banner wording and language.
- Heads-up when old numbers were inflated: do not compare before/after the fix date.
- Only if the client asks about cookies in depth: full blocking before consent vs. cookieless pings.
